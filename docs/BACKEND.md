# Backend setup and API use

Requires Python 3.12+. Install with `python -m pip install -e '.[test]'`, run tests with `python -m pytest`, and start the API with `uvicorn scrapeflow.api:app --reload`. The default SQLite file is `scrapeflow.db`; set `SCRAPEFLOW_DATABASE_URL` to change it. Tables are created on startup. Schema changes require a manual migration in this MVP.

Create a JSON source with `POST /api/v1/sources` and body `{"name":"Example","kind":"json","url":"https://example.com/feed","config":{"kind":"json","items_path":"data.items","fields":{"external_id":"id","title":"name","url":"url"}}}`. Trigger a synchronous run with `POST /api/v1/sources/{id}/runs`. Read `/api/v1/runs/{id}/logs`, `/api/v1/records`, and `/api/v1/stats` for results. HTML sources use `item_selector` and per-field `selector`/`attribute` objects as described in [ARCHITECTURE.md](ARCHITECTURE.md). JSON `items_path` may be `$` for a top-level array.

Ready-to-use sources are in `examples/quotes.json` and `examples/photos.json`. With the backend running, execute `python examples/run_examples.py` to register and run both. The quotes site has no per-quote permalink: the example uses quote text as `external_id` and its author page as `url`. The photos example uses the first album to keep the response bounded. These examples require live public network access; automated tests use offline fixtures.

An extraction yielding zero items fails the run by default and logs the `extract` stage. For a source where an empty result is expected, set `"allow_empty": true` inside its HTML or JSON `config`. Use this only when an empty result is valid for that source. Duplicate identities within one response also fail the run without persisting partial records. When no external ID exists, the normalized record URL is the stable identity, so title changes create versions.

Only public HTTP(S) sources on ports 80 and 443 are accepted. The fetcher rejects resolved internal IP destinations, blocks redirects, ignores environment proxy settings, uses a 10-second timeout and a 2 MB response limit. Use this tool only on resources you are permitted to access; respect site terms and rate limits. The hostname is resolved during validation and again by the HTTP client; an address can change between those lookups. This is not complete DNS rebinding protection. Deployments processing untrusted URLs need network-level egress controls that block internal destinations. Authentication, scheduling, migrations, and a frontend are outside this phase. Sources with run or record history cannot be deleted, preserving their audit trail.
